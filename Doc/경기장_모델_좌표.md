# 경기장 모델 좌표 안내

`Tools/make_stadium.py`가 만드는 모델의 좌표와 치수입니다. 스크립트 위쪽 상수를 바꾸고 다시 실행하면 값이 달라지므로, 수정 후에는 이 표도 함께 고쳐 주세요.

```bash
python Tools/make_stadium.py
```

## 파일

| 파일 | 내용 | 삼각형 |
|---|---|---|
| `Assets/Models/stadium.obj`, `stadium.mtl` | 고정 경기장 전체 | 3,586 |
| `Assets/Models/hole.obj`, `hole.mtl` | 수비 구멍 1개 (원점 중심) | 112 |
| `Assets/Models/ball.obj`, `ball.mtl`, `ball.png` | 공 (원점 = 중심, 반지름 0.30) + 야구공 텍스처 1024×512 | 440 |
| `Assets/Models/bat.obj`, `bat.mtl` | 배트 (원점 = 손잡이 끝, +X로 길이 2.40) | 140 |
| `Assets/Models/player_red.obj`, `player_blue.obj` + `.mtl` | 선수 인형 (원점 = 발밑, +Z를 바라봄, 키 2.2) | 각 722 |
| `Assets/Models/stadium_preview.png` | 게임 시점 미리보기 | - |
| `Assets/Models/viewer.html` | 모델을 하나씩 골라 보는 자유 시점 3D 뷰어 (더블클릭으로 실행) | - |

경기장과 구멍은 `Tools/make_stadium.py`, 공·배트·선수는 `Tools/make_props.py`, 뷰어는 `Tools/make_viewer.py`로 만듭니다. 모델을 다시 만들었으면 뷰어도 다시 만들어야 반영됩니다.

- 면은 전부 삼각형이고 `f v/vt/vn` 형식입니다. 공을 뺀 나머지 모델의 `vt`는 `0 0` 하나뿐인 자리 채움입니다. `v//vn`이 필요하면 스크립트의 `DUMMY_VT = False`로 바꿉니다(공은 항상 `v/vt/vn`).
- 법선은 면 단위(플랫 셰이딩)이고, 앞면은 반시계 방향이라 `glEnable(GL_CULL_FACE)`를 켜도 됩니다.
- 색은 재질의 `Kd`로 구분하고, 텍스처는 공에만 있습니다(`map_Kd ball.png`). 면은 재질별로 묶여 있어 `usemtl`이 재질당 한 번만 나옵니다.
- 조명탑 전구(`bulb`)만 `Ke`(발광)가 있습니다.

## 좌표계

- 원점은 홈플레이트, `+Y`가 위, `-Z`가 2루(외야) 방향, `+X`가 1루 쪽(화면 오른쪽)입니다.
- 경기장 바닥은 `y = 0`이고, 잔디·흙·선은 `y = 0.02 ~ 0.12` 사이에 얇게 겹쳐 있습니다. 공은 반지름만큼 띄워 굴리면 됩니다.

| 위치 | x | y | z |
|---|---|---|---|
| 홈플레이트 | 0 | 0 | 0 |
| 1루 | 6.36 | 0 | -6.36 |
| 2루 | 0 | 0 | -12.73 |
| 3루 | -6.36 | 0 | -6.36 |
| 마운드(투수판 윗면) | 0 | 0.31 | -6.05 |
| 좌·우 타석 중심 | ±1.2 | 0 | 0 |
| 내야 흙 끝(중앙선 기준) | 0 | 0 | -14.65 |

| 항목 | 값 |
|---|---|
| 베이스 간 거리 | 9.0 |
| 페어 지역 | 홈 기준 `-Z` 방향에서 좌우 45도 |
| 외야 펜스 | 홈에서 반지름 27.0 ~ 27.5, 높이 1.7 |
| 워닝 트랙 | 반지름 25.5 ~ 27.0 |
| 판 전체 범위 | x ±26.6, z 6.1 ~ -47.1, y -2.1 ~ 10.6 |

## 판정에 쓸 수 있는 식

타구 위치 `(x, z)`에서

- 홈에서의 거리: `r = sqrt(x*x + z*z)`
- 좌우 각도: `theta = atan2(x, -z)` (도 단위로 -45 = 3루 파울라인, +45 = 1루 파울라인)
- 파울: `|theta| > 45`
- 펜스 도달: `r >= 27.0`, 이때 공 높이가 1.7보다 높으면 홈런

펜스 안쪽 색 패널은 10도씩 9칸입니다. `index = floor((theta + 45) / 10)`

| index | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|---|
| 색 | 노랑 | 주황 | 노랑 | 빨강 | 주황 | 빨강 | 노랑 | 주황 | 노랑 |
| 의도 | 안타 | 2루타 | 안타 | 3루타 | 2루타 | 3루타 | 안타 | 2루타 | 안타 |

배치는 스크립트의 `ZONES` 목록에서 바꿀 수 있습니다.

## 수비 구멍

- `hole.obj`는 원점 중심이고 바닥 위에 얹는 얇은 링입니다. `glTranslatef(x, 0.03, z)`처럼 옮겨서 그립니다. 0.03은 잔디 줄무늬와 겹치지 않게 하는 여유입니다.
- 검은 안쪽 반지름은 0.85, 테두리 포함 바깥 반지름은 1.27입니다. 아웃 판정은 구멍 중심과의 거리가 0.85 이하인지로 하면 됩니다.
- 외야 잔디는 중앙선 기준 z = -14.65 ~ -25.5 구간이라, 구멍은 `r = 17 ~ 23` 정도에 놓는 것이 잘 보입니다.

## 공, 배트, 선수

- **법선**: 공과 선수의 머리·모자·손은 꼭짓점별 법선(부드러운 음영)이고, 나머지는 면 단위 법선입니다. 로더가 `vn`을 그대로 쓰면 둥글게 보입니다.
- **공 텍스처**: `ball.png`는 가로가 경도, 세로가 위도인 펼친 그림이고, `ball.mtl`의 `map_Kd`로 연결됩니다. 공의 `Kd`는 흰색(1, 1, 1)이라 텍스처 색에 곱해도 그대로 나옵니다. 이미지를 위아래로 뒤집어 불러도 실밥 무늬는 이어진 야구공 모양으로 나오므로, 뒤집기 설정은 신경 쓰지 않아도 됩니다. 로더가 텍스처를 읽지 않으면 흰 공으로 보입니다.
- **공**: 원점이 중심이라 `glTranslatef`만 하면 됩니다. 바닥을 굴릴 때는 `y = 0.30 + 0.12` 정도로 띄워야 선과 겹치지 않습니다.
- **배트**: 원점이 손잡이 끝이고 +X로 뻗어 있습니다. 회전축 위치로 옮긴 뒤 `glRotatef(각도, 0, 1, 0)`으로 돌리면 손잡이를 축으로 스윙합니다. 배트 몸통의 가장 굵은 곳 반지름은 0.14입니다.
- **선수 인형**: 하나를 투수·타자·주자에 모두 씁니다. 기본 방향은 +Z(홈·카메라 쪽)이고, `glRotatef(각도, 0, 1, 0)`으로 돌립니다. 받침 반지름은 0.55입니다.

게임에서 배치할 때 참고할 예시입니다. 회전은 Y축 기준 도 단위입니다.

| 대상 | 모델 | x | y | z | 회전 |
|---|---|---|---|---|---|
| 투수 | `player_blue` | 0 | 0.26 | -6.05 | 0 |
| 타자 (왼쪽 타석) | `player_red` | -1.2 | 0.08 | 0 | 90 |

| 1루 주자 | `player_red` | 6.36 | 0.22 | -6.36 | 0 |
